## Тестирование

Тестирование выполнено с использованием шаблонного класса [`Test`](../headers/test.h), который:
- автоматически прогоняет все тесты из папок с префиксом `test.*.in` / `test.*.out`;
- замеряет время выполнения каждой тестовой функции (в микросекундах);
- сравнивает полученный результат с эталонным из `.out` файла.

Сборка: **Release** (максимальная оптимизация).  
Платформа: Windows, компилятор MSVC.

Полный консольный вывод тестов доступен в файле [`output.txt`](./output.txt).

## Заключение

Все задачи решены корректно, все тесты пройдены.  
Реализованные алгоритмы:
- **Ёлочка** — динамическое программирование на треугольной матрице (bottom‑up).
- **Пятью восемь** — замкнутая формула через числа Фибоначчи (сведение к линейной рекуррентности).
- **Горох** — сложение дробей через НОД (бинарный алгоритм Евклида).
- **Острова** — поиск компонент связности (DFS / заливка).
- **Сарай (наивная версия)** — полный перебор всех прямоугольников O(N²·M²).
- **Сарай (оптимизированная)** — построение гистограмм высот + стек для поиска максимального прямоугольника O(N·M).

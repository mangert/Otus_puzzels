# Задачки на динамическое программирование

**Учебный проект** — решение 6 классических задач на динамическое программирование с тестированием и автоматической проверкой.

## Содержание проекта

- [Полное описание задач приведено в файле tasks.md](tasks.md)

## Структура проекта

```
Puzzels/
├── CMakeLists.txt
├── README.md
│
├── headers/
│   ├── puzzles.h          # объявления всех решений
│   └── test.h             # шаблонный класс для тестирования
│
├── src/
│   ├── main.cpp           # точка входа, запуск тестов
│   └── short_puzzels.cpp  # реализации всех задач
│
├── Tests/                 # тестовые наборы (игнорируются в .gitignore)
│
│
└── report/                # отчётность
    ├── report.md          # сводка результатов
    └── output.txt         # полный консольный вывод тестов
```
⚠️ Исходные тестовые файлы (Tests/) не включены в репозиторий для экономии места.
Результаты их выполнения доступны в report/output.txt.

## Сборка и запуск

Проект собирается с помощью **CMake** (версия ≥ 3.20) и компилятора **MSVC**.

```bash
mkdir out/build/x64-release
cd out/build/x64-release
cmake -DCMAKE_BUILD_TYPE=Release ../..
cmake --build . --config Release
```

Запуск тестов:
```bash
./Puzzels.exe
```
